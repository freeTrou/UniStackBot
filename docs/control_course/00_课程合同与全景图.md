## 全景图(五个单元十二课)

```
第一单元 模型:怎么用数学描述一台电机            ← 第1~2课
  第1课  传递函数:把微分方程变成代数式(电流通道)
  第2课  机械侧:扭矩→转速→位置(积分器出场)
第二单元 频域:为什么工程师都看"频率"            ← 第3~5课 ★全课核心
  第3课  Bode 图:增益与相位的频率画像(Python 上手)
  第4课  极点、零点、转折频率:系统的"关节"
  第5课  延迟 e^(−sτ):最毒的成分(延迟账的数学身份)
第三单元 稳定:修正为什么会让系统爆炸             ← 第6~7课
  第6课  环路增益 L(s)、穿越频率 ω_c
  第7课  相位裕度 PM:45°~60° 判据的来历
第四单元 设计:PID 每一项在干什么                 ← 第8~9课
  第8课  P/I/D 三兄弟(刚度/消稳态/阻尼)
  第9课  零点对消:电流环 PI 的 τ_i = L/R
第五单元 级联与数字:三环、1kHz、全栈             ← 第10~12课
  第10课 级联与带宽分离律(正式证明 5~10 倍)
  第11课 采样与 ZOH:1kHz → 100Hz 的四笔账(正式版)
  第12课 毕业推导:复现 Piper 单关节三环全链 PM 表
```

**学生已具备的直觉资产**(课程实质 = 给它们装数学的腿):
开环/闭环(开车)✔ · 延迟账与 360·f·τ ✔ · 带宽=能跟多快的弯 ✔ · 分离律与共振墙(故事版)✔ · CSP 目标流层 vs MIT 闭环层 ✔
