# M1 · 函数与图像:一台"输入→输出"的机器

> 状态:已授课(2026-09-07) | 时长:30~40min | 先修:无

## 1. 函数 = 一台确定的机器

**函数就是一台机器:塞进一个输入,它必吐出一个输出。**

```
        ┌──────────┐
x ────→ │  机器 f  │ ────→ y = f(x)
        └──────────┘
```

三个要点:

1. **一对一的确定关系**:同一个 x 塞进去,永远出同一个 y(机器不能今天认明天不认);
2. **x 可以是一切可量化的东西**:时间、温度、电压、频率……不一定非叫"x";
3. **y 由 x 算出**,所以也叫"y 是 x 的函数"。

例子(三个,从熟悉到控制):

- 售货机:x = 按的按钮编号,y = 掉出的饮料;
- 出租车:x = 公里数,y = 车费 = 8 + 2.6x(起步价 + 每公里);
- **电机:x = 电流 i,y = 扭矩 τ = Kt·i** ← 第一课的 ②式,它就是个函数。

## 2. 图像 = 机器的"行为档案"

把每个 x 和对应的 y 画在坐标纸上(x 横轴,y 纵轴),得到图像。**图像的价值:机器的性格一眼看穿。**

以出租车为例,y = 8 + 2.6x:

```
y
25 ┤                    ●
20 ┤              ●
15 ┤        ●
10 ┤  ●   (起步价 8:x=0 时 y=8,图像从 8 起跳)
   └─┬────┬────┬────→ x
     0    2    4   公里
```

能直接读出的信息:

- **起点**:x=0 时 y=8(没坐也收起步价);
- **斜率**:每往右 1 格,y 涨 2.6(**越陡,涨得越快**——这个"陡"就是 M2 的导数,提前混个脸熟);
- **形状**:一条直线 → 这台机器"性格简单",叫**线性**。

## 3. 线性 vs 非线性(控制理论的第一道分水岭)

- **线性机器**:图像是直线(或过原点的直线)。输入翻倍,输出翻倍;两个输入叠加,输出也叠加。**好办——数学上能精确算**;
- **非线性机器**:图像弯的。电机磁饱和(电流太大扭矩不再涨)、摩擦、死区……**难办——只能在某个工作点附近"假装是直线"来处理**。

**整门控制理论的隐藏前提:我们把一切机器都"线性化"之后才动工。**非线性真实存在,但工程做法是在工作点附近取直线近似(这个手法叫"小信号线性化",第 10 课会正式讲)。现在只需要记住:**这门课处理的机器,图像都是直的或近似直的。**

## 4. 本课与控制理论的接口

把第一课那张"电机画像表"用今天的语言重述:

```
G(jω) 是一台机器:
   输入 x = 频率 ω(一个具体的振动快慢)
   输出 y = (增益, 相位) 两个数
它的图像(Bode 图)告诉你:这台电机"对每种快慢的指令,跟得多准、落后多少"
   —— 第三课我们亲手画它。
```

所以"研究传递函数"翻译成人话就是:**研究这台以频率为输入的机器的性格**。函数、图像、线性——今天的三个词,到第三课全部会长出具体的样子。

## 作业 M1-1~3(口算/画图级)

- **M1-1**:出租车上例。坐 6 公里付多少?若图像斜率变成 3.2,含义是什么?
- **M1-2**:电机扭矩函数 τ = Kt·i,Kt=2。画它的图像(i 横轴,τ 纵轴,i 从 0 到 5)。它是线性还是非线性?
- **M1-3**(概念):温度计 x=实际温度,y=显示温度。若显示永远比实际高 1°,图像长什么样?这算"线性"吗?

## 参考答案

<details><summary>M1-1</summary>

8 + 2.6×6 = 23.6。斜率变 3.2 = 每公里更贵(涨价),图像更陡。
</details>

<details><summary>M1-2</summary>

过原点的直线:i=0→τ=0;i=5→τ=10。线性(且比出租车更"纯":连起步价都没有)。
</details>

<details><summary>M1-3</summary>

y = x + 1:一条直线,只是整体上移 1。**算线性**(直线平移仍是线性关系;严格说这叫"仿射",工程上一律当线性处理)。
</details>
