# 预备课 L0.1 · 三角函数、弧度、相位

> 状态:已授课(2026-09-07) | 目标:学完本课,"正弦""滞后 90°""相位"这些词全部变成画面。

## 1. 正弦是什么:转圈的人和他的影子

一个人在原地匀速转圈(俯视),旁边立一面墙,灯光平射——他在墙上的**影子**会:

- 从中间 → 升到最高 → 回到中间 → 落到最低 → 回到中间,循环往复。

影子高度随时间的变化曲线 = **正弦 sin**。

- 转一整圈 = 影子完整起伏一次 = **一个周期**
- 匀速转圈 → 影子高度是时间的正弦函数,**这就是"正弦信号"的全部含义**

## 2. 弧度:用"半径"量角度

角度有两种单位:度(一圈 360°)和**弧度**(一圈 2π)。

弧度的定义:角度 = **走过的弧长 ÷ 半径**。

| 圈的部分 | 度 | 弧度 |
|---|---|---|
| 整圈 | 360° | 2π ≈ 6.28 |
| 半圈 | 180° | π ≈ 3.14 |
| 四分之一圈 | 90° | **π/2 ≈ 1.57** |

控制理论一律用弧度(因为 ω 直接就是"每秒转多少弧度")。**换算只记一条:90° = π/2,其余按比例。**

## 3. 角频率 ω:每秒转多少弧度

- 转一圈 2π 弧度,用时 T 秒 → 角频率 **ω = 2π/T**(rad/s)
- 换算成"每秒多少次"(频率 f):**f = ω/2π**

例:ω = 1000 rad/s → f = 1000/6.28 ≈ 159 Hz(每秒转 159 圈)。
——第一课表格里那两个数字的关系,现在你知道了。

## 4. 相位:两个人转圈的"先后差"

两个人同速转圈,但 B 比 A **晚出发 1/4 圈**:

- 任意时刻,A 的影子高度和 B 的影子高度**不一样**(B 还没走到 A 的位置)
- 这个固定差距就叫**相位差 = 90°(π/2)**

术语:"B **滞后** A 90°"= B 影子的高度曲线,是把 A 的曲线**向右平移 1/4 周期**得到的。

**为什么控制理论痴迷这个**:正弦信号之间,幅度可以比大小,而"谁先谁后"只能用相位比。后面所有"滞后多少度"的判断(修正来得太晚 = 系统不稳),全靠它。

## 5. sin 和 cos:同速,差 90°

sin 和 cos 就是**两个相差 1/4 圈的转圈影子**:

```
cos(t) 比 sin(t) 领先 90°      (cos 先到峰值)
等价地说:sin(t) 比 cos(t) 滞后 90°
```

**先记住这条**,L0.4 会证明它,然后第一课"积分器恒定滞后 90°"自动变成看得见的画面。

## 6. 本课公式卡片(全部)

```
一圈 = 2π rad = 360°
ω = 2π·f            (角频率 rad/s ↔ 频率 Hz)
相位差 = 转圈出发的先后差,用角度/弧度表示
sin 与 cos 同频,互差 90°(π/2)
```

## 作业 P1~P3(口算级)

- **P1**:ω = 628 rad/s,等于多少 Hz?
- **P2**:一个正弦滞后另一个"半圈",相位差是多少度、多少弧度?
- **P3**:A、B 同速转圈,A 影子在最高点时,B 影子恰在中间(上升途中再过 45° 才到最高)。A 领先 B 多少度?

## 参考答案

<details><summary>P1</summary>

f = ω/2π = 628/6.28 = 100 Hz。
</details>

<details><summary>P2</summary>

半圈 = 180° = π rad。
</details>

<details><summary>P3</summary>

B 到最高还需 45°,说明 A 已经过最高点 45°?不——A 在最高点、B 还差 45° 到最高,即 A 领先 B **45°**。
</details>
