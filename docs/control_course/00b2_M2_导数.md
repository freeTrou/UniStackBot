# M2 · 导数:变化率 = 斜率

## 1. 从"多陡"到"变化率"

M1 里出租车斜率 2.6 的含义:**每往右 1 公里,y 涨 2.6 元**——即"y 随 x 的变化率"。

直线的变化率处处相同(所以一个斜率就够)。但曲线呢?开车:起步时里程曲线平缓,踩油门后越来越陡——**不同时刻,变化率不一样**。

**导数 = 每一瞬间的变化率** = 该点图像的斜率(在该点贴一根直尺,直尺的陡度)。

```
        y
        │        ╱
        │      ╱      ← 这里陡(变化率大)
        │    ╱
        │__╱           ← 这里缓(变化率小)
        └────────── x
```

## 2. 汽车上现成的两个导数

车里装两个表,它们的关系就是导数关系:

```
里程表(位置)  ──导数──→  速度表(变化率)  ──导数──→  加速度表(变化率的变化率)
     θ              dθ/dt = ω                  dω/dt = a
```

- **速度是里程的导数**:里程每秒涨多少;
- **加速度是速度的导数**:速度每秒涨多少。

符号读法:`dθ/dt` 读作"θ 对 t 的导数",意思就是"θ 每秒变化多少"。

## 3. 推冰块(导数版)

恒定力推冰块(质量 m):F = m·a,即**加速度恒定**。用两个表描述:

```
加速度表:  ────────  恒定
速度表:    ／／／／   直线上升(每秒涨同一口)
里程表:    ∕ ∕       越来越陡(曲线)
```

**三张表是同一件事的三个导数层级**:里程(原函数)→速度(一次导数)→加速度(二次导数)。恒定力把最上层钉死,下两层自动长成"直线"和"曲线"。

——这就是 M3 积分的预告,也是控制课第二课"恒定扭矩 → 速度线性涨 → 位置抛物线"的数学身世。

## 4. 回到电机的第一课(导数让 ①式变得可亲)

第一课的 ①:`u = R·i + L·di/dt`

现在逐词读:

- `R·i`:电阻项,只看当前电流多大(不关心变化);
- `L·di/dt`:**电感项,只看电流变化多快**(电流不动,这一项为零)。

**电感的性格:反对电流变化。**变化越快,它顶出的反电压越大——这就是第一课 Bode 图里"高频时电感挡住电流"的数学身世:高频 = 电流变化极快 = di/dt 巨大 = 电感项吞掉全部电压。

## 5. 符号卡片

```
dθ/dt  :θ 每秒变化多少(θ 的导数)
d²θ/dt²:导数的导数(θ 每秒变化率的变化率 = 加速度)
导数大 = 图像陡 = 变化剧烈
导数为零 = 图像平 = 此刻不变(山顶/谷底/平台)
```

## 作业 M2-1~3

- **M2-1**:里程表 θ(t) = 3t²(米,t 秒)。求速度 θ̇(t)=dθ/dt;t=2s 时速度多少?t=0 时里程为 0 但速度是多少?
- **M2-2**:电感 L=1mH,电流在 1ms 内从 0A 匀速涨到 10A。di/dt = ?电感顶出多少伏?(u_L = L·di/dt)再用一句话:这解释了第一课 Bode 图的什么现象?
- **M2-3**(概念):转速 ω 是转角 θ 的导数。那么"加速度"是谁的导数?恒定扭矩下加速度长什么样?由此推:速度曲线长什么样、位置曲线长什么样(推冰块三行图)。

## 参考答案

<details><summary>M2-1</summary>

dθ/dt = 6t;t=2s 时 12 m/s;t=0 时速度 = 0(里程 0 和速度 0 是两回事:导数是变化率,不是数值)。
</details>

<details><summary>M2-2</summary>

di/dt = 10A/0.001s = 10000 A/s;u_L = 0.001 × 10000 = **10V**。解释:电流变化越快 di/dt 越大,电感反电压越大 → 高频时电感项吞掉全部电压 → 电流跟不上(第一课 −45°/−90° 的身世)。
</details>

<details><summary>M2-3</summary>

加速度是速度的导数(dω/dt)。恒定扭矩 → 恒定加速度 → 速度直线上升 → 位置抛物线(越来越陡)。即推冰块三行图。
</details>
