# 数学预备单元 · 路线图(从高等数学遗忘处重新挂网)

> 定位:控制理论课程的数学地基。学生大学修过高数,全部遗忘——本单元是**重新挂网**,不是零基础教学:每个概念先唤回画面,再给定义。
> 原则:画面先行 → 数字第二 → 符号最后。每课 30~40 分钟,配 3 道口算作业。
> 毕业标志:M7 结束后,重读第一、二课如读故事;then 回主课第三课。

## 七课路线

| 课 | 内容 | 控制理论用途 | 关键画面 |
|---|---|---|---|
| M1 | 函数与图像 | 整门课研究一个函数 G | 自动售货机:投币(输入)→出货(输出) |
| M2 | 导数 = 变化率 = 斜率 | di/dt、dθ/dt | 汽车速度表 = 里程表的导数 |
| M3 | 积分 = 累积 = 面积,与导数互逆 | 积分器 1/s、θ=∫ω | 推冰块:力→速度涨→位置陡 |
| M4 | 指数函数 e、衰减 e^(−t/τ) | 一阶系统响应、时间常数 τ | 开水凉掉:先快后慢,永远凉不透 |
| M5 | 三角函数、弧度、相位 | 正弦信号语言 | 转圈的人与影子(已成文 00a) |

| M7 | e^(jωt) 合体 | 第一课推导的黑话全部解锁 | 匀速旋转的箭头 |
