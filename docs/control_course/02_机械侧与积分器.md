# 第二课 · 机械侧:扭矩→转速→位置,积分器出场

> 状态:已授课(2026-09-07) | 先修:第一课(传递函数、极点)
> 上课作业成绩:T1 ✅ A · T2 ✅ A · T3 ✅ A(教授承担题目笔误:20kHz 奈奎斯特 = 10kHz,非 500Hz)

## 1. 接上第一课的尾巴:电流 → 扭矩

第一课的 ②式现在登场:电流产生扭矩。

```
τ = Kt · i        (Kt = 扭矩常数,Nm/A;减速器后折算值,典型几 Nm/A)
```

于是链条往前接了一环:**电压 → 电流(第一课)→ 扭矩(乘 Kt,纯增益,无动力学)**。

## 2. 机械方程:扭矩推的是什么

牛顿第二定律的旋转版:

```
J·dω/dt = τ − B·ω − τ_load
```

- J:折算到该轴的总惯量(kg·m²)——**本课主角**
- B:粘滞摩擦(Nm·s/rad),通常很小
- τ_load:外负载(重力、接触),控制课先归零

传递函数(扭矩→转速):

```
ω(s)/τ(s) = 1/(J·s + B)
```

**又是一阶系统!**和第一课的 1/(Ls+R) 结构完全同构:J↔L、B↔R。

极点:B/J。代入典型数字 J=0.5 kg·m²,B=0.01:

```
极点 = B/J = 0.02 rad/s ≈ 0.003 Hz —— 几乎在直流!
```

**读法:在我们关心的一切频率(1Hz 以上),1/(Js+B) ≈ 1/(Js)——纯积分器。**摩擦小到可以忽略时,扭矩对转速就是一个纯粹的积分关系。

## 3. 积分器登场:1/s

积分器 `1/s` 的频率画像(本课唯一的新公式,必背):

```
|1/jω| = 1/ω   → −20dB/dec(频率×10,增益×1/10)
∠1/jω = −90°   → 恒定滞后九十度
```

物理直觉:积分 = 累积。恒定扭矩推 0.5kg·m² 的惯量,转速**线性增长**没有尽头——输入不变、输出一直涨,这正是"滞后 90°"的时域含义(正弦的积分是余弦,恰好差四分之一周期)。

## 4. 再积分一次:到位置,−180° 出现

位置是转速的积分:`θ = ∫ω dt`。所以扭矩→位置的传递函数:

```
θ(s)/τ(s) = 1/(J·s²)        ← 双重积分器!
```

频率画像:**−40dB/dec、恒定 −180°**。

**−180° 的物理含义(本课最重要的一个画面)**:给恒定扭矩,位置不是"到位停住",而是**匀加速一直走**——

```
τ 恒定 → ω 线性涨 → θ 按抛物线涨
你想要"位置动一动",它给你的却是"永远加速"
```

这就是为什么位置控制天生困难:对象自带 −180°,而闭环稳定要求环路总相位离 −180° 足够远(相位裕度)——**位置环必须自己补出相位来**(阻尼项 kd·ė,第八课 PID 的 D 之所在)。对比:速度环对象只有 −90°(单积分),所以速度环整定容易。

## 5. 减速器:惯量的 N² 放大

减速比 N(出轴转 N 分之一圈):

- 扭矩放大 N 倍,速度缩小 N 倍(以速度换扭矩)
- **负载惯量反射到电机轴:× N²**

```
J_电机轴总惯量 = J_转子 + N² · J_负载
例:N=10,负载 0.3 kg·m² → 反射 30 kg·m² —— 负载统治一切
```

这解释了之前讨论的两个事实:①"惯量比大的关节共振频率低"(J 大 → ω_r=√(K/J) 低);②为什么谐波减速器关节的一阶共振普遍只有几百 Hz。

## 6. 本课总图:从电压到位置的完整画像

```
u ──1/(Ls+R)──→ i ──×Kt──→ τ ──1/(Js+B)≈1/Js──→ ω ──1/s──→ θ
     一阶         增益        积分器(−90°)        积分器(再 −90°)
   极点≈直流                 └──────── −180° ────────┘
```

- 电流通道:第一课,一阶,极点 160Hz(Piper);
- 扭矩:纯增益;
- 转速:积分器;
- 位置:双积分,−180°,**位置控制的全部困难由此而来**。
