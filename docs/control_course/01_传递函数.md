# 第一课 · 把电机写成数学:传递函数

> 状态:已授课(2026-09-07),待学生提交作业
> 先修:无(高中复数 + 微分即可)

## 1. 物理事实

最简单的直流电机,线圈加电压 u:

```
u = R·i + L·di/dt        ① 电压 = 电阻消耗 + 电感存储(基尔霍夫电压定律)
F = Kt·i                 ② 电流产生力(安培力)—— 本课先不用,第二课登场
```

本课只看 ①(电流怎么响应电压)——这正是**驱动器电流环看到的全部世界**。

## 2. 从微分方程到"输入输出画像"

①是微分方程 `di/dt = (u − R·i)/L`,直接解只给"某时刻的答案"。

工程师的问法不同:**不问某一时刻,问"对每种频率的正弦电压,电流怎么响应"**。

推导(只需一步):设 u、i 都是正弦 `e^(jωt)` 形态,代入 ①:

```
u·e^(jωt) = R·i·e^(jωt) + L·(jω)·i·e^(jωt)
两边消去 e^(jωt)(每项都乘它,约掉):
i/u = 1/(R + jωL)
```

**微分方程 → 代数式。**这个 `G(jω) = 1/(R+jωL)` 就是**传递函数**:

- `|G(jω)|` = 增益 = 该频率下电流幅度/电压幅度
- `∠G(jω)` = 相位 = 该频率下电流落后电压多少度

> **为什么消掉 e^(jωt) 是合法的**:e^(jωt) 的导数是 jω·e^(jωt)——正弦的导数还是同频正弦,只是幅度相位变了。所以线性系统对正弦的稳态响应永远是同频正弦,差异全部浓缩在 G(jω) 里。这就是这门课只用"频率"说话的原因。

## 3. 代入真实数字(R=1Ω, L=1mH)

```
G(jω) = 1/(1 + jω·0.001)
```

三个频率点(复数除法:分母取模和幅角):

| ω (rad/s) | 分母模 \|1+jωL\| | 增益 \|G\| | 相位 ∠G |
|---|---|---|---|
| 0(直流) | 1 | 1(0 dB) | 0° |
| 1000(=159Hz) | √2 ≈ 1.414 | 0.707(−3dB) | **−45°** |
| 10000(=1591Hz) | ≈10.05 | ≈0.1(−20dB) | −84° |

**读表**:
- 直流时电感 = 导线,电流完全跟随(增益 1、零滞后);
- 频率↑ → 感抗 ωL↑ → 电流幅度缩、滞后增,极限 **−90°**(纯电感性质);
- **转折频率 ω = R/L 处恰好 −45°、−3dB**——所有一阶系统的通用签名。

## 4. 三个术语(正式认领)

| 术语 | 定义 | 本例 |
|---|---|---|
| **极点 pole** | 使分母为零的 s 值;增益开始下跌、相位滑向 −90° 的拐点 | s = −R/L(频率坐标 1000 rad/s) |
| **转折频率 corner** | 极点对应的频率(−3dB 位置) | 1000 rad/s ≈ 159 Hz |
| **−20dB/dec** | 过极点后频率×10、增益×1/10 的固定斜率 | 一阶系统签名 |

→ 对应推导文档:"电气极点 160Hz"= 1000 rad/s ÷ 2π。

## 作业 T1~T3

- **T1**:R=2Ω、L=1mH,求极点(rad/s 与 Hz);R 翻倍后极点变高还是变低?
- **T2**:证明 ω→∞ 时增益 ∝ 1/ω(−20dB/dec)且相位 → −90°。
- **T3**(概念):电流环采样 20kHz,可控制的电流变化频率上限是极点 159Hz 还是奈奎斯特 10kHz?为什么两者都对、又各对一半?

## 参考答案(学生提交后展开)

<details><summary>T1</summary>

极点 = R/L = 2000 rad/s ≈ 318 Hz。**变高**(电阻更强,电感相对更小,电流跟得更快)。
</details>

<details><summary>T2</summary>

ω→∞ 时 |G| = 1/√(R²+(ωL)²) ≈ 1/(ωL),即 ∝1/ω → 频率×10 增益×1/10 = −20dB/dec;∠G = −arctan(ωL/R) → −90°。
</details>

<details><summary>T3</summary>

两者是**不同维度的上限**:奈奎斯特 10kHz 是"采样能不能看见"(信息论上限);极点 159Hz 是"物理能不能响应"(对象能力上限)。**有效带宽 = min(两者)再打折**——本例中对象极点先卡死,电流环闭环带宽最终 ≈1.5~2kHz(第二阶段 PM 推导),与两者都不相等。结论:数字控制的有效带宽 = min(采样税, 对象能力)再乘稳定裕度。
</details>
