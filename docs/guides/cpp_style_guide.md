# UniStackBot C++ 代码规范

> 全工程适用。只约束形式与结构,不约束业务逻辑与实现写法——并发/实时代码纪律见 `docs/guides/linux_rt_guide.md`(第二部分),测试纪律见各链 smoke 脚本约定,不在本规范内。
> 规范来源:现有代码惯例的显式化 + 本文拍板的裁决。

## 一、大括号与控制流

1. **Allman,无例外**:所有 `{`、`}` 独立成行——类、函数、命名空间、控制流全部适用
2. 三个非"块"例外:成员默认值初始化、lambda 捕获列表后的参数表同行跟随、`{...}` 列表初始化允许同行
3. **switch 裁决**:case 体的大括号与 `case` 标签同级;**`break` 写在 `}` 之后**(大括号只负责作用域,break 属于 switch 控制流);`return`/`continue` 属于用例逻辑,留在块内
4. **每个 switch 必须有 `default:`**,哪怕所有取值已覆盖——未处理的分支只放一句注释说明,禁止静默空过
5. **一行一句**:分号结尾的语句不共享行;单句循环体也必须换行加大括号

## 二、格式与断行

6. **Tab 缩进**,显示宽 4,禁止空格缩进与混用;块注释续行 ` * ` 除外
7. 行宽**建议 ≤120,无硬限制**
8. **单行优先**:函数签名(声明/定义/lambda 参数表)、if/while/for 条件、语句(日志宏、函数调用)默认写一行——**不受 120 建议约束**
9. 断行阈值约 **160 列**,超过才断行:签名在 `(` 后换行、每参数一行;条件在 `&&`/`||` 运算符**之后**断行;调用参数续行缩进
10. 文件尾**恰好一个空行**

## 三、文件与头文件

11. 文件名 = 主类名的蛇形形式(`sim_control_hardware.hpp` ↔ `SimControlHardware`)
12. include guard 形如 `包名__文件名_HPP_`
13. include 顺序:本包头 → C++ 标准库 → ROS/第三方(各组内字母序)
14. 头文件自包含(每个头自带全部依赖);公开声明在 `include/`,实现在 `src/`(模板/头文件库除外)

## 四、命名

15. 类型 `PascalCase`;函数/方法 `camelCase` 动词开头;框架回调保留框架签名(如 `on_init`/`read`)
16. 常量 `constexpr` + `k` 前缀 PascalCase;成员变量 `snake_case_` 尾下划线;局部/参数 `snake_case`;`enum class` 值 `UPPER_SNAKE`;宏(尽量避免)`UPPER_SNAKE`
17. **名字必须完整表意**:完整单词优先;只接受领域通用缩写(ROS 语境的 cmd/vel);自造缩写(svc/req/buf 这类)禁止
18. 布尔成员用形容词/状态句式(`paused_`);判断谓词做成 `is_xxx()` 方法而非存字段

## 五、类与成员

19. **class/struct 分工**:有不变量或管理资源 → class、数据私有;纯数据载体 → struct 全公开,顶多带简单谓词方法
20. **布局**:函数与数据成员**各占一个 `private:` 段**(先函数、后数据),数据段放类尾,段内各自集中、不得交错
21. 数据块按角色分组注释,顺序:RT 数据 → RT 依赖 → 非实时基础设施;配套成员相邻声明
22. 成员声明一行一个;默认值写在声明处(`x_{false}`),回调/构造里只赋来自参数的值
23. 禁 per-object `const` 成员(白白删掉赋值运算符);常量用 `static constexpr`(类内)或匿名命名空间 `constexpr`(文件内)
24. 禁可变 `static` 成员(变相全局状态);文件级 `static const`(如 logger)例外
25. **所有权写在类型里**:`unique_ptr` = 独占、`SharedPtr` = 共享;裸指针/引用 = 借用,必须注释由谁保活

## 六、C++ 方言

26. 标准 **C++17**,编译 `-Wall -Wextra -Wpedantic`,**零警告交付**
27. **错误处理 = 显式错误流**:进程内错误 100% 走显式通道——自己的代码不抛异常,错误一律返回值 + message(与 ros2_control 回调风格一致);错误返回的函数标 `[[nodiscard]]`,配合零警告红线把"忽略错误"挡在编译期;STL/ROS 中**明确会抛**的调用(`std::stod`/`.at()`/`new` 等)在调用边界用 try/catch 接住、翻译成返回值——**异常只存在于边界翻译层,永不进入控制链路**
28. `auto` 仅在类型冗长(迭代器/lambda)且右侧自明时用;遍历可用 `auto &`/`const auto &`
29. 优先引用;所有权转移用 `std::unique_ptr`;裸 `new` 禁止

## 七、注释

30. 中文,**讲为什么、不讲是什么**
31. 形式:单行 `//`;多行块 `/* */`(续行 ` * ` 对齐);行尾 `//`——**不用 `///` 和 `///<`**
32. **坑注释必须留在原地**:谁踩的、什么现象、怎么绕过
33. 契约常量在定义处写设计依据(上界来源、为什么是这个数)
34. 魔法数字禁止裸奔:`constexpr` 起名或注释量级来源
