## 2. Oracle 基准生成（v2, 关节正推采样）

**核心转变**: v1 笛卡尔随机碰运气（45% 命中、姿态覆盖单一）→ v2 关节空间正推（100% 命中、全姿态覆盖）。

```
可达样本: Halton 低差异序列(素数基 2,3,5,7,11,13,17) → 关节限位盒内采样
          → FK 正推末端位姿(天然可达) → 解析解库复核全部限位内解 → 真解+分层标签
不可达样本: 70% 远超臂展带 + 30% 贴边界带(近奇异候选) → 解析解库复核无解(剔假不可达)
分层标签: r=<半径> br=<最近分支> d_br=<距分支中心 L1>
```

**关键教训（实测代价）**: v1 的 90/90 是姿态覆盖不足下的虚高（只测朝下姿态）；v2 全姿态后暴露 2 个边界失败（99.5% 才是真实水位）。**200 样本定位问题够用，验收必须 ≥500**（90 样本 95% 置信区间 ±8%）。

**入库纪律**: 文件头带生成环境指纹（ssik 版本/日期/自检结果）；生成时抽样自检过我们自己的 FK；CI/运行时零 ssik 依赖（ssik 的权威性固化为数据，脆弱性隔离在生成脚本）。

**换臂动作**: 换 URDF 跑 `test/gen_ik_oracle.py <robot> 600`，一步。

## 3. 分层实验链（归因顺序 = 排除顺序）

**原则: 先证明算法正确，再排查工程参数。** xarm7 的实际排查链（耗时两天，本文档的目标是让换臂压缩到小时级）：

```
第 0 环  主循环无辜性证明: 失败目标 + 它自己的真解作种子
         → 1 迭代收敛 = DLS/误差/限位处理全对 (✓ xarm7 实测: iters=1)
第 1 环  奇异排除: lam_gain 1→10 扫描, 成功率纹丝不动 (59→59→59→59)
         → 不动 = 与奇异无关; 动 = 先修 λ 自适应
第 2 环  重启数量排除: restarts 40→80→150, 全部 59
         → 不动 = 不是种子数量, 是种子分布或出口过滤
第 3 环  失败画像: 失败样本 r 全 < 0.65(近基座), 解构型距中心 9~11 rad(全身大扭转)
第 4 环  解空间聚类: 4 分支代表提取 → 直接做种子 → 仍 59 (!)
第 5 环  参数语义审计: 找到 jump_threshold=1.5 在冷启动下误杀全部远解
         → jump=100 + 分支种子 → 90/90 一击命中
```

**归因链的分工**: 0 环区分"算法错 vs 工程错"；1-2 环排除法；3-4 环找结构；5 环找语义冲突。**不要跳过 0 环直接调参**——不证明主循环无辜，后面全是在错误假设上烧时间。

**停止猜测纪律**: 每个假设必须配一个最小实验。xarm7 教训——"折叠构型种子"盲改一次无效（59→59），四分支种子"无效"（其实是被粘性拒了，表象相同）；换区分散改动，用数据淘汰假设。

## 4. 参数语义审计表（xarm7 定稿值）

| 参数 | 定稿值 | 语义 | 换臂重标? |
|---|---|---|---|
| `jump_threshold` | 1.5 rad | **仅 STREAMING**（解距种子 L1 上限，连续性保证） | ✅ 按关节范围/典型运动幅度 |
| SolveMode | — | 显式意图声明；冷启动禁粘性 | ❌ 设计模式直接用 |
| 分支代表种子 | 4 组关节角 | COLD_START 的确定性种子（数据驱动先验） | ✅ 重新聚类 |
| `w_rot` | 1.0 | 姿态误差权重 | 建议扫 0.3/0.5/1.0 |
| `lam_gain` | 3.0 | Wampler λ 自适应增益 | 建议扫 1/3/6 |
| `restarts` | 40 | 前半中心带±30%，后半全区间 | 按收敛域 |
| boxed DLS | 迭代内 clamp 进线搜索 | 限位主动盒约束 | ❌ 通用 |
| 收敛邻域信任步 | err<10×容差 直接接受 | 线搜索在收敛边缘的误杀防护 | ❌ 通用 |
| 线搜索容差 | err×1.001+1e-12 | 严格 < 会杀边缘收敛的种子 | ❌ 通用 |

**xarm7 踩坑记录（防复发）**:
- `jump_threshold` 一个参数两个场景 → SolveMode 解耦（本文档核心案例）
- 迭代内 clamp 无线搜索 → 边界踏步更差; 有线搜索 → 2/90 → 59/90（boxed 组合是关键）
- 出口 clamp 伪装界内解 → 被 FK 回代断言当场抓住 → 改"收敛后限位检查, 越界=该种子失败"
- 零空间项在收敛邻域 → 极限环永不收敛 → err<1e-3 关闭
- 姿态误差 log(RaᵀRb) 是末端系, 雅可比是基座系 → 混系=发散（必须转基座系）

## 5. 验收标准模板

| 指标 | 线 | 测法 |
|---|---|---|
| 冷启动成功率 | ≥95%（≥500 可达样本） | COLD_START + 分支种子 |
| 流式成功率 | 100% | STREAMING + 上一解种子, ≥100 点连续轨迹 |
| 不可达拦截 | 100% | ≥150 不可达样本, 绝不出假解 |
| 收敛解质量 | 回代 100% | FK(解)≈目标 <1e-6 |
| 冷启动 p50 / p99 | <5ms / <50ms | 含全部重启耗时 |
| 轨迹连续性 | 相邻解增量 <0.15 rad | 无跳分支 |

**xarm7 定稿成绩（600 样本）**: 418/420=99.5% / 101/101 / 180/180 / 90/90 回代 / 0.29ms p50 / 40.5ms p99 / 0.063 rad 最差增量。2 个失败样本 meta 标签定位（距分支中心 ~18 rad 稀疏边缘），已知边界非缺陷。

## 6. 换臂标准操作流程（SOP）

```
1. 新臂 URDF 入 arms/<robot>/ 四件套（含限位声明）
2. python3 test/gen_ik_oracle.py <robot> 600          # Oracle 一步生成
3. bash test/run_ik_test.sh <robot>                    # 默认参数跑分
4. 失败归因: 按本文 §3 六环排查链逐环执行（从第 0 环开始, 不跳步）
5. 解空间聚类: python3 对 oracle 解集 k-means → 新分支中心 → 更新 kBranch 表
6. 重标: jump_threshold / 分支中心 / 分层边界（本文 §4 表的 ✅ 项）
7. 流式回归: 轨迹连续性 101 点全过
8. 验收: §5 模板全绿 = 收官
```

工具链现状: ①Oracle 生成器 ✅（`gen_ik_oracle.py` v2）; ②③④（归因分析器/聚类器/配置模板化）以脚本+本表形式存在, 未独立工具化——触发再固化（第三台臂接入时）。

## 7. 方法论的边界（诚实声明）

- 本流程验证**数值 IK 求解器**; 几何正确性由 FK 侧保证（TF 对拍, 见 `check_fk_tf.sh`, 实测 4e-13）——IK 验收以前置 FK 验收为前提
- Oracle 权威 = ssik 的解析覆盖; 若新构型 ssik 不可解（掉入通用数值类）, 可达性真值降级, 需改用 FK 采样自证（生成器 v2 的关节正推天然提供, 不依赖 ssik 复核也能用, 只是解集不如解析全）
- 冷启动 99.5% ≠ 100%: 剩余 0.5% 是解空间稀疏边缘, 追到 100% 的路径是 KDTree 目标导向种子库（本次评估后不需要, 样本扩大后若跌破 95% 再上）
