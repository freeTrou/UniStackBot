## 一、源资料必须包含的四项（缺一项卡死对应环节）

> 判据：是不是物理/设计真值。是 → 只能来自源头，转换器与我们都无法推导。
> 根因：URDF 这四项不是几何的翻译，是**设计决策的编码**——cad2urdf 只能翻译几何，翻译不了没做过的决策。

### ① 每关节限位（lower / upper，最好带 effort / velocity）

- **为什么推不出来**：机械限位是挡块/结构设计决定，CAD 几何里看不见。
- **现状证明**：7 个关节全部同一行 `<limit lower="-1.57" upper="1.57" effort="10" velocity="5"/>` ——转换器固定默认值签名。
- **对照 stationlite**（厂商官方 URDF 内嵌真值）：`lower="-2.824" upper="2.824" effort="27" velocity="5.5"` / `lower="-0.209" upper="3.508"` / `lower="-3.193" upper="0"`——每关节各不相同且非对称，只有真实机器才写得出来。
- **需要形态**：一张 7 行表。

### ② 关节零位定义（或导出时各关节角度表，含正方向定义）

- **为什么推不出来**：零位是标定/设计约定，不是几何量。
- **现状证明**：joint origin 带非零 rpy——joint1 `rpy="1.8326 0 0"`（105°）、joint2 `rpy="1.5708 1.309 -1.5708"`：**装配姿态被烘焙进文件**，当前"零位"是摆件姿势。
- **对照 stationlite**：origin 全部 `rpy="0 0 0"`、xyz 干净（`0.024 0 0.117`）——厂商把树建在定义好的零位上，origin 只剩连杆几何尺寸。
- **需要形态**：7 个数 + 各关节正方向定义；或**摆到零位重导一版**。

### ③ 每连杆质量属性（质量 / 质心 / 惯量张量）

- **为什么推不出来**：来自材料密度 + 电机线缆等实物；源 STEP 含片体（2173 个非实体面片几何），转换器只能对壳体积估算。
- **现状证明**：基座 mass=0.192 kg **比每级连杆都轻**（物理不成立）；末端 link7 反而 1.353 kg（2202 个片体堆的）。
- **对照 stationlite**：基座 mass=2.239 kg、全张量、质心 z=0.217——厂商按材料+实物算好的账。
- **需要形态**：表格，或**实体版模型**（我们自算）。

### ④ 法兰 / 工具安装面定义（位置 + 朝向，相对哪级 link）

- **为什么推不出来**：机械接口是图纸约定。
- **现状证明**：URDF 全文 `gripper/flange/tool` 0 命中，树到 link7 即止——CAD 装配体里没有"工具法兰"零件。
- **对照 stationlite**：树尾显式有 `left_linkgripper` 一等 link，CM 的 `tip_link` 直接指它。
- **需要形态**：一张图或一组坐标。

## 二、导出规范（同一次导出必须做对，不需额外数据）

1. **摆到零位再导出**（或带角度参数版）——当前为装配姿态直导；
2. **结构件实体化**（片体→实体，至少主要结构件）——当前"含片体"版；
3. **装配分组挂对 link**——当前 2202 个片体全堆在关节 7（拖 J7 外壳整体跟甩）；
4. **关节编号 + 正方向确认**——我们暂定 joint1..joint7（基座→末端），需厂商确认。

- 额定负载 / 工作空间 / 重复定位精度（验收容差 + OTG `max_acceleration/max_jerk` 定值用）。
